# Downly

Save YouTube videos and playlists as MP4 or MP3. Free desktop app for Windows and Linux.

**Website and downloads: https://laurenz19.github.io/downly-releases/**

This repository hosts Downly's public releases and its website. Pick your file from the [latest release](https://github.com/Laurenz19/downly-releases/releases/latest):

| System | File |
|---|---|
| Windows | `Downly-Setup.exe` (or `Downly-x64.msi` for IT deployment) |
| Linux | `Downly-x86_64.AppImage` or `Downly-amd64.deb` |
| Browser extension (Chrome, Edge, Brave) | `Downly-Companion.zip` |

Releases are published automatically. Don't edit them by hand, and don't rename their files: the website links to them by name.
